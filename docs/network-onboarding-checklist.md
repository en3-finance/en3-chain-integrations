# Network Onboarding Checklist

## Technical Review

- Confirm official chain ID.
- Confirm network type: testnet or mainnet.
- Confirm native currency metadata.
- Confirm block explorer availability.
- Confirm RPC access model.
- Confirm transaction confirmation behavior.

## Security And Risk Review

- Identify chain-specific operational risks.
- Confirm no private RPC credentials are committed.
- Confirm demo wallet behavior is isolated from production custody.
- Confirm integration scope is documented.

## Business Review

- Confirm the network is appropriate for the target wallet use case.
- Confirm any public wording avoids unverified partnership claims.
