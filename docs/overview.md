# Overview

en3-chain-integrations contains public EVM network configuration and integration templates.

The repository is chain-neutral. It documents how en3 evaluates possible EVM-compatible network integrations without making any single network the center of the product.

## Public Use

- Review the example EVM network configuration.
- Follow the onboarding checklist.
- Use placeholders until official public network parameters are selected.
- Keep credentials and customer-specific settings out of git.
